# テニス 固定ペア総当たり 対戦表

**ここから使えます → https://takaakiueno.github.io/rakuraku/index.html**

## 概要

1面で固定ペアの総当たり戦を行うときの、試合の順番を作るツールです。

## 使い方

1. **組数**(4〜12)を選んで「決定」を押します。押すたびに別の順番になります。
2. 対戦表は1行1試合です。`1 - 6` は「ペア1 対 ペア6」の試合です。
3. 終わった試合にチェックを入れると、次の試合が色付きで表示されます。
4. 「csv出力」で、次の形式の CSV ファイルを保存できます。ゲーム数の列は空欄なので、Excel で結果を書き込めます。

```
試合,ペア,ペア,ゲーム数,ゲーム数
1,3,4,,
2,2,5,,
```

**全試合消化する(待ち時間を優先)**: 最後まで消化する予定のときにチェックします。待ちが少し減りますが、途中で打ち切ると試合数が2試合違うペアが出ることがあります。

表の下の「偏りのチェック」に、ペアごとの試合数・最大待ち(次の出番までに待つ試合数の最大)・最大待ちになった回数・連続出場の回数が出ます。

## データの保存について

対戦表とチェックは、使っているブラウザの中に自動で保存され、再読み込みしても残ります。サーバーには何も送られず、他の端末とは共有されません。

## 順番の決め方

次の条件を、上から順に優先して満たす順番を探します。

1. **連続出場なし**: 同じペアが2試合続けて出ない(4組だけは仕組み上2回出ます)。
2. **最大待ちを最小に**: 次の出番まで待つ試合数の最大を、できるだけ小さくします。
3. **途中で打ち切っても公平**: どの試合で打ち切っても、ペアごとの消化試合数の差が1以内(「全試合消化する」のときは2以内)。
4. **最大待ちになる回数を少なく**: 上の条件を満たす中から、最大待ちになる場面が最も少ない順番を選びます。

計算には約1.5秒(「全試合消化する」のときは約3秒)かかります。

| 組数 | 試合数 | 最大待ち |
|---|---|---|
| 4・5 | 6・10 | 2試合 |
| 6・7 | 15・21 | 3試合 |
| 8・9 | 28・36 | 4試合 |
| 10・11 | 45・55 | 5試合 |
| 12 | 66 | 6試合 |

最大待ちは、どの組数でも理論上これ以上は減らせない値です。
